### 🧬 The Vibe Coder Manifesto

1. **Rule #1:** If the code runs, **never ask *why* it runs**. Just bask in the vibes.
2. **Rule #2:** Never debug manually if you can still copy-paste the error message to an AI.
3. **Rule #3:** *Unit Tests?* The ultimate test is pushing straight to production. If it explodes, ask AI to apologize.
